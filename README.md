# Prädiktive Analyse von Windkraftanlagen  
**Optimierung und Analyse der Leistung von Windkraftanlagen mit maschinellem Lernen**

## 📌 Projektbeschreibung

Dieses Projekt untersucht die Leistung von Windkraftanlagen unter Verwendung prädiktiver Modelle aus dem Bereich des maschinellen Lernens. Ziel ist es, die Produktionsmuster zu analysieren, kritische Einflussfaktoren zu identifizieren und die Performance durch geeignete ML-Algorithmen zu prognostizieren und verbessern.

Die Analyse umfasst:
- Datenexploration und -bereinigung
- Feature Engineering
- Modellierung mit Regressions- und Baumbasierten Algorithmen (z. B. Random Forest, XGBoost)
- Evaluation mit Metriken wie MAE und RMSE
- Visualisierung relevanter Ergebnisse
